# IGNIS

Purpose
- Governed recovery and repair (automated and human-in-the-loop).

Responsibilities
- Execute recovery playbooks, rollbacks, or mitigation steps when triggered.
- Coordinate with Sentinel for authorization and with RCM for context/evidence.
- Emit status updates to Signal for operator awareness.

Integration
- Input: recovery triggers, authorized commands from Sentinel, context from RCM.
- Output: recovery actions, status reports, and post-recovery evidence.

Next steps
- Provide example playbooks and a recovery simulation environment.
- Define success/failure metrics and rollback strategies.
